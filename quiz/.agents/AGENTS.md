Your task is to prepare an interactive artifact that simulates practice quizzes for a live quiz where I am expected to explain design decisions for my assignment1 implementation. 

Here are the assignment guidelines:

```
Hey everybody,

Hope assignment 1 is wrapping up well for everyone :) It's time for the first oral exams.

Format. We are going to ask you questions about your implementation for 10 minutes. The artifact should be an interactive form that asks a series of questions (5-10) that cover the content of the colored boxes in the pdf that ask for reflection/design elements in the assignment, as well as general reflections on the assignment. 
```

The mock quiz questions should ask for specific references in the codebase too. 

After each question is submitted, there should be a grader that runs and provides feedback to score each question's answer on a scale of 1-5, with suggestions for improvement if there are any, as well as the easy option to ask followup questions around the feedback. 

This should be interactive, as submitting each question for grading should make a call back to the agent for evaluation.

At the end of the quiz, there should be a way to save the quiz (including all grading, my responses, the grading of my responses, and the followup questions etc) statically to quiz/ directory.
